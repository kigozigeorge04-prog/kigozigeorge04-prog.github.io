💡 The 8 Key Features of Any Symptom

When taking a history, always characterize the symptom using:
1. Site - Where exactly?
2. Onset - When did it start? Sudden or gradual?
3. Character - What does it feel like?
4. Radiation - Does it spread anywhere?
5. Associated features - What else occurs with it?
6. Timing - How long does it last? How often?
7. Exacerbating/Relieving factors - What makes it better or worse?
8. Severity - How bad is it? (0-10 scale)

🩸 HIV Clinical Pearls

• Always ask about ART adherence (missed doses in last 30 days)
• Check latest viral load - suppression is <50 copies/mL
• Screen for TB with chronic cough >2 weeks
• WHO staging helps assess immunosuppression
• Ask about disclosure and partner testing
