🌡️ Fever — Clinical Guide
📋 Key Questions
  • Duration: <7 days = acute; 1–3 weeks = typhoid/TB; >3 weeks = PUO
  • Pattern: Continuous (typhoid), intermittent (malaria), remittent (TB)
  • Highest temp: >38.3°C = significant; >40°C = hyperpyrexia
  • Rigors: Uncontrollable shaking = bacteraemia/malaria
  • Associated: Cough, rash, neck stiffness, dysuria, diarrhoea
🚨 Red Flags
  • Fever + altered consciousness → cerebral malaria/meningitis
  • Fever + non-blanching rash → meningococcaemia
  • Fever + inability to drink → severe illness
🤧 Cough — Clinical Guide
📋 Key Questions
  • Duration: Acute <2w, subacute 2–8w, chronic >8w
  • Productive? Dry (viral), purulent (bacterial), blood-stained (TB)
  • Timing: Night (asthma/GORD), morning (COPD), after meals (GORD)
  • Fast breathing: RR >60/min (<2m), >50/min (2–12m), >40/min (1–5y)
  • TB contact: Any household chronic cough or TB contact?
🚨 Red Flags
  • Cough + fast breathing + chest indrawing → severe pneumonia
  • Haemoptysis → TB until proven
  • Sudden onset in toddler → inhaled foreign body
💩 Diarrhoea / Vomiting — Clinical Guide
📋 Key Questions
  • Duration: Acute <14d, persistent 14–30d, chronic >30d
  • Stool character: Watery (secretory), bloody/mucus (dysentery), fatty (malabsorption)
  • Dehydration: Drinking normally, sunken eyes, skin turgor, lethargy
  • Vomiting: Projectile (pyloric stenosis), bilious (obstruction)
🚨 Red Flags
  • Unable to drink → severe dehydration, admit
  • Bloody diarrhoea + fever → dysentery
  • Rice-water stool → cholera
🍼 Poor Feeding — Clinical Guide
📋 Key Questions
  • Duration: Acute (hours–days) or gradual (weeks)?
  • Description: Weak suck? Refuses feeds? Tires easily?
  • Vomiting after feeds? Posseting (normal), GORD, projectile (pyloric stenosis)
  • Weight loss or failure to gain?
🚨 Red Flags
  • Unable to feed at all → admit immediately
  • Poor feeding + lethargy + fever in neonate → sepsis
  • Poor feeding + projectile vomiting → pyloric stenosis
⚠️ Convulsions — Clinical Guide
📋 Key Questions
  • Duration: <5 min (simple), 5–30 min (prolonged), >30 min (status)
  • Type: Generalised tonic-clonic, focal, absence
  • Fever at the time? Febrile seizure vs meningitis/cerebral malaria
  • Post-ictal state: Back to normal within 30 min vs prolonged drowsiness
🚨 Red Flags
  • Seizure >5 min → diazepam IV/PR
  • Seizure + fever + altered consciousness → cerebral malaria/meningitis
  • Afebrile seizure → check blood glucose immediately
🔴 Skin Rash — Clinical Guide
📋 Key Questions
  • Blanching? Glass test — non-blanching = meningococcaemia
  • Type: Macular, papular, vesicular, petechial, purpuric
  • Distribution: Face → trunk → limbs (measles), trunk → outward (chickenpox)
  • Itching? Scabies (worse at night), urticaria, eczema
🚨 Red Flags
  • Non-blanching rash + fever → meningococcaemia (emergency)
  • Rash + mucosal involvement → SJS/TEN
  • Measles rash in malnourished child → vitamin A immediately
🟡 Jaundice — Clinical Guide
📋 Key Questions
  • Age of onset: <24h (pathological), 2–7d (physiological), >14d (prolonged)
  • Stool colour: Normal (unconjugated) vs pale/clay (conjugated)
  • Urine colour: Dark (conjugated) vs normal (unconjugated)
  • Pallor: Pallor + jaundice = haemolysis (G6PD, malaria)
🚨 Red Flags
  • Jaundice <24h → haemolytic disease, phototherapy
  • Pale stools + dark urine → conjugated jaundice, urgent referral
  • Jaundice + altered consciousness → kernicterus
🩺 Pain — SOCRATES
📋 SOCRATES Framework
  • S — Site: Point with one finger
  • O — Onset: Sudden or gradual?
  • C — Character: Sharp, dull, colicky, burning?
  • R — Radiation: Does it move anywhere?
  • A — Associations: Nausea, vomiting, fever, diarrhoea?
  • T — Timing: Constant or intermittent?
  • E — Exacerbating/Relieving: What makes it worse/better?
  • S — Severity: 0–10 scale
🚨 Red Flags
  • Severe pain + guarding + rebound → surgical abdomen
  • Colicky pain + red currant jelly stool → intussusception
  • Pain + scrotal swelling → testicular torsion (6-hour window)
💨 Difficulty Breathing — Clinical Guide
📋 Key Questions
  • Onset: Sudden (foreign body), hours (pneumonia), gradual (TB/cardiac)
  • Sounds: Stridor (upper airway), wheeze (lower airway), grunting (severe)
  • Work of breathing: Chest indrawing, nasal flaring, head nodding
  • SpO₂: ≥95% normal, 90–94% mild, <90% severe
🚨 Red Flags
  • Stridor + drooling → epiglottitis, do NOT examine throat
  • SpO₂ <90% → high-flow oxygen
  • Silent chest in asthma → near-fatal asthma
💧 Swelling — Clinical Guide
📋 Key Questions
  • Location: Neck, abdomen, groin, limb, scrotum
  • Pain: Tender (inflammatory) or painless (neoplastic)
  • Duration: Days (acute) vs weeks–months (chronic)
  • Consistency: Fluctuant (cyst/abscess) vs hard (bony/tumour)
🚨 Red Flags
  • Rapidly growing painless mass → Burkitt's lymphoma
  • Groin swelling + pain + unable to reduce → incarcerated hernia
  • Painless abdominal mass <5 years → Wilms tumour
😴 Lethargy / Irritability — Clinical Guide
📋 Key Questions
  • Severity: Quieter (mild), drowsy (moderate), unresponsive (severe)
  • Fever present? CNS infection (malaria, meningitis, sepsis)
  • Blood glucose: <2.5 mmol/L → treat NOW
  • Convulsions? Post-ictal lethargy vs ongoing
🚨 Red Flags
  • Unable to wake the child → ABC first
  • Lethargy + fever → cerebral malaria or meningitis
  • Glucose <2.5 → 10% dextrose 2 ml/kg IV
🩸 Pallor — Clinical Guide
📋 Key Questions
  • Duration: Sudden (haemolysis) vs gradual (iron deficiency)
  • Dark urine? Haemoglobinaemia (malaria, G6PD)
  • Jaundice? Haemolytic anaemia
  • Diet & pica: Iron deficiency, lead poisoning
🚨 Red Flags
  • Severe pallor + lethargy + RR >40 → severe anaemia, transfuse
  • Pallor + dark urine + fever → blackwater fever / G6PD crisis
  • Pallor + splenomegaly + collapse in sickle cell → splenic sequestration
🦟 Neck Stiffness — Clinical Guide
📋 Key Questions
  • Fever? Fever + neck stiffness = meningitis
  • Rash? Non-blanching = meningococcaemia
  • Conscious level: Alert → LP, drowsy → CT first
  • TB contact? TB meningitis
🚨 Red Flags
  • Neck stiffness + fever → ceftriaxone IV immediately
  • Non-blanching rash + neck stiffness → benzylpenicillin
  • Neck stiffness + reduced consciousness → raised ICP, do NOT do LP
👂 Ear Discharge — Clinical Guide
📋 Key Questions
  • Duration: <2w (AOMP), >12w (CSOM)
  • Discharge: Purulent (bacterial), foul (Pseudomonas), blood-stained (trauma)
  • Pain before discharge? TM perforation
  • Mastoid tenderness? Mastoiditis
🚨 Red Flags
  • Ear discharge + mastoid tenderness → mastoiditis, IV antibiotics
  • Blood-stained discharge after head trauma → CSF leak
  • Chronic foul discharge + hearing loss → cholesteatoma
💧 Oedema — Clinical Guide
📋 Key Questions
  • Site: Bilateral lower limbs (kwashiorkor/cardiac), face (nephrotic)
  • Pitting? Pitting (low protein), non-pitting (lymphoedema)
  • Diet: Low protein diet → kwashiorkor
  • Frothy urine? Nephrotic syndrome
🚨 Red Flags
  • Oedema + severe wasting + hypothermia → complicated SAM, F-75 milk
  • Oedema + anuria → acute kidney injury
  • Oedema + flaky paint skin + hair changes → kwashiorkor
🫃 Abdominal Distension — Clinical Guide
📋 Key Questions
  • Onset: Rapid (obstruction) vs gradual (ascites/mass)
  • Bowel movements: Constipation (obstruction) vs diarrhoea (gastroenteritis)
  • Vomiting: Bilious vomiting → obstruction
  • Abdominal tenderness: Rigid abdomen → peritonitis
🚨 Red Flags
  • Bilious vomiting → intestinal obstruction
  • Rigid abdomen → peritonitis
📉 Failure to Thrive — Clinical Guide
📋 Key Questions
  • Growth chart decline? Crossed ≥2 centiles → significant
  • Feeding: Poor intake vs projectile vomiting
  • Weight: <2nd centile → organic cause
  • Regression in milestones?
🚨 Red Flags
  • Weight <2nd centile → investigate
  • Regression in milestones → neurodegenerative
🦴 Limping / Bone Pain — Clinical Guide
📋 Key Questions
  • Fever? Fever + painful joint → septic arthritis (emergency)
  • Trauma history? Falls, sports injuries
  • Night pain? Malignancy
  • Sickle cell disease? Sickle crisis → dactylitis
🚨 Red Flags
  • Hot, swollen, immobile joint → septic arthritis
  • Night pain + weight loss → malignancy
🔴 Haematuria — Clinical Guide
📋 Key Questions
  • Timing: Initial (urethral), terminal (bladder), total (renal)
  • Pain? Loin pain (stone), dysuria (UTI)
  • Risk factors: Schistosomiasis (endemic in Uganda)
🚨 Red Flags
  • Painless total haematuria → malignancy
  • Clots + retention → surgical emergency
🚿 Dysuria / Frequency — Clinical Guide
📋 Key Questions
  • Fever? Fever + dysuria → pyelonephritis
  • Urine colour: Cloudy/foul → UTI
  • Poor stream? Obstruction
🚨 Red Flags
  • Fever + vomiting → pyelonephritis
  • Poor stream → obstruction
🗣️ Developmental Delay — Clinical Guide
📋 Key Questions
  • Regression? Loss of skills → neurodegenerative
  • Hearing? Failed hearing test → ENT referral
  • Milestones: Which milestones have been achieved?
🚨 Red Flags
  • Loss of acquired skills → neurodegenerative
👁️ Eye Problems — Clinical Guide
📋 Key Questions
  • Discharge: Purulent (conjunctivitis), watery (viral)
  • Photophobia: Corneal ulcer / iritis
  • Systemic symptoms: Fever + rash → measles/meningococcaemia
🚨 Red Flags
  • Painful red eye + photophobia → iritis / glaucoma
  • Sudden loss of vision → emergency
🩸 Bleeding / Bruising — Clinical Guide
📋 Key Questions
  • Gum bleeding / epistaxis? Platelet dysfunction
  • Petechiae + fever? Meningococcaemia
  • Haemarthrosis? Haemophilia
🚨 Red Flags
  • Non-blanching rash + sick child → meningococcaemia
  • Haemarthrosis → haemophilia
😶 Unconsciousness / Coma — Clinical Guide
📋 Key Questions
  • GCS: ≤8 → intubate
  • Glucose: <2.5 → IV dextrose
  • Seizures + coma: Cerebral malaria
🚨 Red Flags
  • GCS ≤8 → protect airway
  • Seizures + coma → cerebral malaria
⚖️ Malnutrition / Wasting — Clinical Guide
📋 Key Questions
  • Weight-for-age: < -3 Z-score → SAM
  • Bilateral pitting oedema? Kwashiorkor
  • MUAC: <11.5 cm → SAM
🚨 Red Flags
  • Hypothermia, hypoglycaemia → complicated SAM
  • MUAC <11.5 cm → severe acute malnutrition
🍼 Neonatal Problems — Clinical Guide
📋 Key Questions
  • Jaundice onset: <24h = pathological
  • Feeding and tone: Poor tone + poor feeding → sepsis
  • Respiratory distress: RDS, pneumothorax
🚨 Red Flags
  • Lethargy, poor feeding, hypothermia → neonatal sepsis
  • Respiratory distress → RDS / pneumothorax
💡 General Clinical Prompts
📋 Always Remember
  • Always check danger signs first (lethargy, inability to feed, convulsions)
  • For pain: use SOCRATES framework
  • In Uganda: always screen for malaria and HIV
  • Red flags are medical emergencies — do not delay referral
